# 결정구조(crystal structure) 문제 대비

선배 후기에 "crystal structure인가 뭔가를 문제 내고 꽤 어려웠다"고 적혀 있습니다(비공식, `../README.md` 2절). 어떤 구조가 어떤 형식으로 나올지는 알 수 없으므로, 제공된 자료에서 **구조 정보가 실제로 나오는 곳**을 모두 모았습니다. 무기 쪽은 이 문서, 유기 실험 2의 X선 구조는 `../organic/02_exp2_aldol_DA.md`의 해당 절을 보세요.

출처 규칙은 `../README.md` 참고. 구조에 대한 사실은 무기 매뉴얼 [M-무기]와 강의노트 [L-무기]에 있는 것만 "확인된 사실"로 적었습니다. [G]는 일반 화학 지식, [추론]은 해석입니다.

## 1. 구조 그림을 받았을 때의 점검 순서

시험에서 구조 그림이나 표가 주어진다면 아래 순서로 읽으면 빠짐이 없습니다.

1. **원자 목록**: 중심 금속과 리간드는 무엇인가? 리간드의 공여 원자는 무엇인가?
2. **배위수(coordination number)**: 금속에 직접 결합한 원자(CBC 방식으로는 L과 X의 수) 개수. CBC에서는 η⁵-Cp를 하나의 L₂X로 세므로 페로센의 C.N.은 6. [L-무기 s181]
3. **기하(geometry)**: 팔면체, 사각뿔, 삼각쌍뿔 등. "찌그러짐(distorted)"이 있는지.
4. **cis/trans 관계**: 어느 리간드가 서로 마주 보는가(trans)?
5. **전자 계수**: CBC로 원자가 전자 수와 산화수(O.S.). 18전자인가 16전자인가? (`03_theory_and_analysis.md` 5절)
6. **d 전자 수와 스핀**: d⁶ 저스핀/고스핀, 홀전자 수 → 자기적 성질(반자성/상자성).
7. **대칭**: 점군(D₅h, D₅d), 거울면, 반전 중심 [G].
8. **형태(conformation)**: 예) 두 Cp 고리가 staggered인가 eclipsed인가?
9. **결합 길이와 각도**: 같은 종류의 결합이 거의 같은 길이인가(예: 페로센 Cp의 C-C가 서로 비슷한가)? 서로 다른 자리의 같은 리간드의 결합 길이 차이는 무엇을 뜻하는가(예: trans 영향 [G])?
10. **스펙트럼과의 연결**: 구조가 IR, NMR, 자기감수율, MS 결과를 어떻게 설명하는가?

## 2. RuCl₂(PPh₃)₃ [M-무기 p3, Figure 1; L-무기 s55, s59]

### 확인된 사실 (매뉴얼)
- X선 구조는 **Placa(La Placa)와 Ibers**가 발표(Inorg. Chem. 1965, 4, 778). 시료는 Vaska가 준비하고 연구했음. [M p3]
- Ru(II)는 **5배위(five-coordinated)**. 화합물은 **반자성(diamagnetic)**이고 **단량체(monomeric)**. [M p3]
- Ru는 **찌그러진 사각뿔(distorted square pyramid)**의 중심 쪽에 있음. **밑면**에 **trans인 Cl 원자 두 개와 trans인 P 원자 두 개**, **꼭짓점(apical)**에 **P 원자 하나**. [M p3]
- 강의 슬라이드 제목은 "trans-[RuCl₂(PPh₃)₃]". [L s55]
- 수분과 용매에 민감하므로 건조 용매와 CaCl₂ 건조관을 씀. [M p5]

### 이 사실에서 바로 끌어낼 수 있는 것 (계산)
| 질문 | 답 | 근거 |
|---|---|---|
| 배위수 | **5** (Cl 2 + P 3) | [M p3] |
| 산화수 | **+2** (Cl 두 개가 X) | CBC. `03` 5.4절 |
| d 전자 수 | Ru²⁺: **d⁶** | Ru 8족, 8 - 2 = 6 [G] |
| 전자 수(CBC) | 8 + 3×2 + 2×1 = **16전자** | `03` 5.4절 |
| 기하 | 사각뿔(찌그러짐) | [M p3] |
| 자기적 성질 | **반자성**(홀전자 없음) | [M p3] |
| trans 쌍 | 밑면의 **Cl-Ru-Cl**이 trans, 밑면의 **P-Ru-P**가 trans | [M p3] |
| 인 리간드의 구분 | 밑면 두 개(서로 trans) + 꼭짓점 하나. **세 P가 모두 동등하지 않음** | [M p3] |
| 16전자인데 안정한 이유 | 5배위로 **빈 자리**가 있음. 이 자리가 촉매 반응(기질 결합)에 쓰일 수 있음 | [추론] |

### 비어 있는 여섯 번째 자리에 대한 필기 [필기+G]
강의 슬라이드(s55)의 구조 그림에는 점선이 그려져 있고 손글씨로 "PPh₃ 중 하나가 배위 자리를 막는다(blocks coordination site)"는 취지의 필기가 있습니다(글씨가 흐려 확실하지 않음). 일반적으로 이 착물에는 한 PPh₃ 페닐 고리의 C-H가 비어 있는 자리 쪽에서 금속에 약하게 상호작용(아고스틱 상호작용)한다고 알려져 있으나, 이 내용은 제공된 자료에서 확인되지 않습니다. 시험 전에 강의 슬라이드의 그림을 직접 보고 확인하세요.

### 결합 길이는 문제로 나올 때
꼭짓점 Ru-P와 밑면 Ru-P의 길이, Ru-Cl 길이가 표로 주어질 수 있습니다. 제공된 자료에는 수치가 없으므로 수치를 외울 수는 없고, **표를 해석하는 법**을 익히세요.
- 같은 종류의 결합이라도 자리(꼭짓점/밑면)에 따라 길이가 다르면 **전자적, 입체적 환경이 다르다**는 뜻입니다.
- P-Ru-P, Cl-Ru-Cl 각도가 180°에서 얼마나 벗어나는지로 "찌그러진 정도"를 말할 수 있습니다.

### 실험과의 연결
- RuCl₃·xH₂O에서 Ru(III) → Ru(II) 환원과 PPh₃ 산화(→ OPPh₃). 생성물이 **단량체**, **반자성**인 것은 구조와 일치합니다. [M p3; L s55]
- 촉매 반응에서는 RuCl₂(PPh₃)₃가 **전촉매**이고 실제 활성종은 hydride(RuH₂(PPh₃)₃ 등)로 제안됩니다. [M p4]

## 3. 페로센 Fe(η⁵-C₅H₅)₂ [M-무기 p12-13; L-무기 s136-139]

### 확인된 사실
- 샌드위치 구조 **[Fe(η⁵-C₅H₅)₂]**는 1952년 Wilkinson, Rosenblum, Whiting, Woodward가 보고. [M p12]
- 두 가지 형태: **eclipsed(D₅h 대칭)**와 **staggered(D₅d 대칭)**. 에너지 차이는 작음. 문헌에는 **응축상(고체, 액체)에서는 staggered**, **기체상에서는 eclipsed**가 발견된다고 적혀 있음. [M p12; L s138]
- 이론 연구는 대부분 기체상이나 용액을 다루므로 eclipsed가 상대적으로 더 많이 연구됨. [M p12]
- **18전자 규칙**을 따르는 안정한 화합물. 금속 중심은 두 Cp 리간드에 의해 보호됨. [M p13]
- 두 Cp의 10개 MO가 Fe의 AO와 상호작용해 페로센의 MO를 만들고, 18개 전자가 모두 낮은 에너지의 **결합 MO**에 들어가며 **반결합 MO에는 전자가 없음** → 안정. [L s139] (MO 도표는 CM3111에서 다룸)
- Cp의 C-C 결합은 **벤젠의 C-C 결합과 비슷한 성질**(방향족)을 가지며, 그 때문에 벤젠과 비슷한 반응을 함. [L s139]
- 바닥 전자 상태는 **저스핀(low-spin)**. [L s138]
- 강의 슬라이드에는 **"η⁵"는 다섯 탄소가 모두 금속에 결합하고 전자가 비편재화**되어 있음을 뜻한다는 필기가 있음. [필기, s136]

### 이 사실에서 바로 끌어낼 수 있는 것
| 질문 | 답 |
|---|---|
| 배위수(CBC) | **6** (L₂X × 2) |
| 산화수 | **+2** |
| 전자 수 | **18** (Fe 8 + Cp 5 × 2) |
| Fe의 d 전자 | Fe²⁺: **d⁶**, 저스핀 → 홀전자 0 → **반자성**일 것 [L s138-139 + G] |
| staggered의 대칭 | **D₅d** |
| eclipsed의 대칭 | **D₅h** |
| 대칭 요소(차이) | D₅h는 두 고리를 나누는 **수평 거울면(σh)**이 있고, D₅d는 **반전 중심(i)**이 있음 [G] |
| 어느 형태가 고체 결정에서 관찰될 것인가 | **staggered**(응축상) [M p12] | [보충 2026-11-04: 이는 상온 단사정계 결정 기준의 서술이다. 저온 삼사정계 상은 거의 eclipsed로 보고되어 있다. 11절 참고, 저온 상의 세부는 [G]]
| 기체상 | **eclipsed** [M p12] |
| 두 형태의 에너지 차이 | **작다**. 그래서 형태 사이 변환이 쉬움(고리 회전) [M p12; 회전은 G] |

### 구조와 분석 결과의 연결 [추론+G]
- **¹H NMR**: 10개의 수소가 모두 화학적으로 동등하다면 하나의 신호. 고리가 빠르게 회전하고 두 고리가 같은 환경이기 때문. 본인의 스펙트럼으로 확인.
- **자기감수율**: 저스핀 d⁶ → 홀전자 없음 → 반자성. FeCl₂·4H₂O(고스핀, 홀전자 4개, 상자성)와 대비. [L s172]
- **UV-vis, IR**: 본인 스펙트럼으로 확인. 문헌값은 제공된 자료에 없음.
- **ESI-MS**: 분자 이온 피크는 분자량 186.04 부근. 철의 동위원소 분포는 제공된 자료에 없으므로 [G] 시험 전에 확인.

## 4. 유기 실험 2의 X선 결정구조 [M-유기 p9, p12]

유기 실험 2에서는 **생성물의 X선 결정구조가 주어지고 해석**하도록 되어 있습니다. IR과 NMR로는 좁혀질 뿐, 정확한 입체화학(endo/exo, 그리고 CO가 떨어졌는지)은 **X선 구조에서 명확하게** 확인된다는 것이 핵심입니다. 자세한 내용은 `../organic/02_exp2_aldol_DA.md`의 "X선 구조 해석" 절에 있습니다.

## 5. X선 구조가 알려 주는 것과 못 알려 주는 것 [G]

| 알려 주는 것 | 못 알려 주거나 한계 |
|---|---|
| 원자의 3차원 위치: 연결 관계, 결합 길이와 각도, 형태(conformation), 입체화학(상대 배치) | 결정 안의 한 순간의 정적 구조. **용액에서의 동적 거동**(고리 회전, 배위 자리 교환)은 NMR이 더 잘 알려 줌 |
| 배위 기하와 trans/cis 관계 | 수소 원자는 위치를 정확히 알기 어려움 |
| 입체이성질체 구별 (예: endo/exo) | 결정을 얻지 못하면 불가능. 결정이 전체 시료를 대표하지 않을 수 있음(순도) |
| 분자 대칭, 결정 안 분자 배열 | 홀전자 수, 산화수 같은 전자적 성질은 구조에서 간접적으로만 추정 |

## 6. 연습 문제 (정답 포함)

1. RuCl₂(PPh₃)₃의 중심 금속에서 배위수, 기하, trans인 리간드 쌍을 말하라.
   **5배위, 찌그러진 사각뿔. 밑면에 Cl-Ru-Cl이 trans, P-Ru-P가 trans이고 꼭짓점에 P 하나.** [M p3]
2. RuCl₂(PPh₃)₃의 CBC 전자 수와 산화수는?
   **16전자, +2.** (RuL₃X₂: 8 + 6 + 2 = 16)
3. RuCl₂(PPh₃)₃가 반자성인 것은 d 전자 배치로 어떻게 설명되는가?
   **Ru(II)는 d⁶이고 5배위 사각뿔 장에서 전자가 모두 쌍을 이루어 홀전자가 없기 때문.** (매뉴얼은 "diamagnetic"이라고만 서술. 설명은 [추론])
4. 같은 착물이 수분에 민감한 이유와 실험에서의 대응을 쓰라.
   **RuCl₂(PPh₃)₃가 수분과 용매에 민감. 건조 용매(분자체)와 CaCl₂ 건조관이 달린 환류 장치를 사용.** [M p5]
5. 페로센이 "샌드위치"라고 불리는 이유와 헵티시티 기호 η⁵의 뜻을 설명하라.
   **두 개의 평면 Cp 고리가 철을 사이에 둔 구조이고, η⁵는 각 고리의 다섯 탄소가 모두 금속에 결합한다는 뜻.** [M p12; 필기 s136]
6. 고체 페로센 결정에서 관찰될 가능성이 높은 형태는? 그 대칭은?
   **staggered, D₅d.** [M p12]
7. 페로센이 18전자인 것을 보이시오.
   **Fe 8 + 2 × 5(Cp는 L₂X로 5전자) = 18.** [L s180, s184]
8. 페로센이 FeCl₂·4H₂O와 달리 반자성이어야 하는 이유를 쓰라.
   **페로센은 Fe²⁺(d⁶) 저스핀으로 모든 전자가 쌍을 이루지만, FeCl₂·4H₂O의 Fe²⁺는 약한 장 리간드에 의해 고스핀(홀전자 4개, μs = 4.90 B.M.)이기 때문.** [L s168, s172]
9. X선 구조와 NMR이 각각 더 잘 알려 주는 것을 한 가지씩 쓰라.
   **X선: 결정에서의 정확한 3차원 구조와 입체화학. NMR: 용액에서의 동적 거동과 환경의 동등성.** [G]
10. 같은 Ru-P 결합이라도 꼭짓점과 밑면에서 길이가 다르다면 무엇을 시사하는가?
    **두 자리의 전자적, 입체적 환경이 다르다는 것.** 구체적인 값은 제공된 자료에 없음. [G]

## 7. 주차시트에서 가져온 보강 (W2, W6)

- **RuCl₂(PPh₃)₃의 꼭짓점 포스핀은 용액에서 쉽게 떨어진다.** ESI-MS의 기저 피크가 [RuCl(PPh₃)₂]⁺로 나오면 이 해리를 보여 주고, 같은 해리가 촉매 순환에서 배위 자리를 연다. 결정구조에서 꼭짓점 쪽 결합이 다른 자리와 다르게 보이는 것과 연결해 생각할 수 있다. [W2 부록 B, W4 부록 E; 연결은 추론]
- **페로센은 staggered D₅d 기준으로 MO가 그려진다**(eclipsed D₅h에서는 기호만 바뀜). 주결합은 **e1g**(dxz, dyz와 고리 e1), 점유된 꼭대기는 e2g⁴ a1g², LUMO는 e1g\*. 18전자가 모두 결합 또는 비결합 준위에 있어 **반자성**이고 공기 중에서 다룰 수 있다. 자세한 것은 `02_exp2_ferrocene.md` 11.5절. [W6 부록 I]
- 결정구조 문제에서 전자 수 질문이 나오면 CBC(`03_theory_and_analysis.md` 5절)와 MO 설명을 둘 다 말할 수 있어야 한다.
- 연습 문제 추가:
  11. 페로센에서 금속-고리 결합의 주된 상호작용은? **금속의 dxz, dyz와 고리 e1 조합이 겹치는 e1g 쌍.** [W6 I1]
  12. 페로센의 HOMO 영역 전자 배치와 의미는? **e2g⁴ a1g²의 닫힌 껍질이므로 홀전자가 없어 반자성.** [W6 I2]
  13. 페로센의 UV-vis 약한 띠가 어떤 전이이며 왜 약한가? **금속 중심의 a1g/e2g → e1g\*인 d-d 전이이고 중심 대칭 분자에서 Laporte 금지이므로 ε가 약 10².** [W6 I2]

## 8. 결정학 기초 (시험용 압축 정리) [G, 표시한 곳은 [X]]

### 8.1 결정과 격자
- **결정(crystal)**: 원자, 분자가 3차원으로 **주기적**으로 반복 배열된 고체. **비결정(amorphous)**은 장거리 질서가 없어 날카로운 회절점이 없음. [G]
- **격자(lattice)**: 반복 단위를 점으로 바꾼 수학적 점 배열. **결정 = 격자 + 기저(basis, 각 격자점에 붙는 원자/분자)**. [G]
- **단위세포(unit cell)**: 3차원으로 평행이동만 해서 결정 전체를 채우는 최소 반복 상자. handout 표현: "구조 정보를 모두 담고 결정 격자 전체에 반복되는 가장 작은 부피 단위". [X p2]
- **격자상수**: 모서리 길이 **a, b, c**와 각 **α(b-c 사이), β(a-c 사이), γ(a-b 사이)**. 부피 V = abc·√(1 − cos²α − cos²β − cos²γ + 2cosα cosβ cosγ). 단사정계는 V = abc·sinβ. [G]

### 8.2 7개 결정계
| 결정계 | 격자상수 제약 | 최소 대칭 | 예 |
|---|---|---|---|
| 삼사정(triclinic) | a≠b≠c, α≠β≠γ | 없음 또는 반전(1, -1) | 저온 페로센 |
| 단사정(monoclinic) | a≠b≠c, α=γ=90°, β≠90° | 2회축 또는 거울면 1개 | 상온 페로센, 유기 분자 다수 |
| 사방정(orthorhombic) | a≠b≠c, α=β=γ=90° | 서로 수직인 2회 대칭 3개 | P2₁2₁2₁ 결정 |
| 정방정(tetragonal) | a=b≠c, 90°, 90°, 90° | 4회축 1개 | |
| 삼방/육방정(trigonal/hexagonal) | a=b≠c, α=β=90°, γ=120° | 3회축 또는 6회축 | 얼음 Ih |
| 입방정(cubic) | a=b=c, 90°, 90°, 90° | 3회축 4개 | NaCl, 다이아몬드 |
- 결정계는 **격자상수의 숫자가 우연히 같은지**가 아니라 **대칭**으로 정해진다는 점이 함정. 예: β가 우연히 90°에 가까운 단사정계도 있음. [G]
- 이 순서는 **대칭이 낮은 것에서 높은 것**. 유기, 유기금속 화합물은 대칭이 낮은 삼사정, 단사정, 사방정계가 대부분. [G]

### 8.3 14개 브라베 격자(Bravais lattice)
- **P(primitive)**: 격자점이 모서리에만. **I(body-centred)**: 몸 중심(1/2,1/2,1/2) 추가. **F(face-centred)**: 세 쌍의 면 중심 모두. **C(base-centred)**: 한 쌍의 면(ab면) 중심. (R은 삼방정계의 능면체 격자.) [G]
- 14개의 구성: 삼사 P(1), 단사 P, C(2), 사방 P, C, I, F(4), 정방 P, I(2), 삼방 R(1)과 육방 P(1), 입방 P, I, F(3). 합 1+2+4+2+2+3 = 14. [G]
- 중심화 격자는 단위세포 안의 격자점이 늘어남: P 1, I 2, F 4, C 2. 이것이 소멸 규칙의 원인(8.9). [G]

### 8.4 비대칭 단위, Z, Z′
- **비대칭 단위(asymmetric unit)**: 공간군의 대칭 연산으로 결정 전체를 만들 수 있는 **가장 작은 독립 부분**. CIF에 좌표가 실리는 것은 이 부분뿐. [G]
- **Z**: 단위세포 안의 **화학식 단위(formula unit)의 수**. **Z′**: 비대칭 단위 안의 화학식 단위의 수. 관계: **Z = Z′ × (공간군의 일반 위치 수)**. [G]
- 예: P2₁/c의 일반 위치 4개 → 분자가 일반 위치에 있고 Z′=1이면 Z=4. 분자가 **반전 중심 위**에 있으면 분자의 절반만 독립 → Z′=0.5, Z=2. [G]
- 상온 페로센은 단사정 P2₁/a(P2₁/c의 다른 축 설정), Z=2이므로 분자가 반전 중심에 놓임(Z′=0.5). [G] (11절)

### 8.5 대칭 요소
| 요소 | 기호 | 동작 |
|---|---|---|
| 회전축 | 2, 3, 4, 6 | 360°/n 회전 |
| 거울면 | m | 면에 대한 반사 (키랄 아님) |
| 반전 중심 | -1 (i) | 점 대칭 이동, (x,y,z)→(-x,-y,-z) |
| 나사축(screw axis) | 2₁, 3₁, 4₁ 등 | 회전 + 축 방향으로 (n분의 m) 이동 |
| 미끄럼면(glide plane) | a, b, c, n, d | 반사 + 면 방향으로 1/2 이동 |
- **나사축, 미끄럼면은 병진을 포함한 대칭**이라 분자 자체의 점군에는 없고 **결정 안에서만** 나타남. [G]
- 반전 중심, 거울면, 미끄럼면, 회반(-n) 축은 **제2종(반대 손) 연산**. 이런 연산이 하나라도 있으면 키랄 분자의 두 거울상이 함께 있게 됨. [G]

### 8.6 점군과 공간군
- **점군(point group)**: 한 점을 고정하는 대칭(병진 제외). 분자 대칭(D₅h, D₅d, C₂v), 결정의 외형 대칭 표기(32개). [G]
- **공간군(space group)**: 병진까지 포함한 결정 전체의 대칭. 3차원에서 **230개**. [G]
- 공간군 기호 읽기: **첫 글자 = 격자형(P, C, I, F, R)**, 뒤는 세 방향(단사정계는 유일한 b축 방향)의 대칭 요소. 분수 모양 "2₁/c"는 **그 방향에 2₁ 나사축이 있고 그에 수직한 면이 c 미끄럼면**이라는 뜻. [G]
| 공간군 | 읽는 법 | 특징 |
|---|---|---|
| **P2₁/c** (No. 14) | 단순 격자, b축 방향 2₁ + 수직 c-미끄럼면 | 일반 위치 4개. **유기, 유기금속 결정에서 가장 흔함**(약 1/3). 중심대칭 → 라세미체 가능 |
| **P-1** (No. 2) | 단순 격자 + 반전 중심 | 일반 위치 2개. 두 번째로 흔함. 삼사정계 |
| **P2₁2₁2₁** (No. 19) | 세 수직 방향 모두 2₁ 나사축 | 일반 위치 4개. **키랄 공간군(Sohncke)**, 거울상 순수 결정에서 흔함 |
| **C2/c** (No. 15) | C 중심화 + 2회축 + c-미끄럼면 | 일반 위치 8개. 분자가 2회축 위에 놓일 수 있음 |
- P2₁/c, P2₁/a, P2₁/n은 **같은 공간군(No. 14)의 다른 축 선택**. [G]

### 8.7 키랄 공간군과 라세미체
- 공간군 중 **제2종 연산(반전 중심, 거울면, 미끄럼면 등)이 없는 65개**가 **키랄(Sohncke) 공간군**. 대표: P2₁2₁2₁, P2₁, P1. [G]
- **거울상 순수한(enantiopure) 화합물은 키랄 공간군으로만 결정화**할 수 있음. [G]
- **라세미체**는 대개 중심대칭 공간군(P2₁/c, P-1, C2/c)에서 두 거울상이 반전 중심으로 연결되어 한 결정 안에 함께 있음(**라세미 화합물**). 두 거울상이 따로따로 결정화하면 **자발 분할(conglomerate)**(드묾). [G]
- **결정의 거울상 구조**와 **절대 배치(absolute configuration)**는 **이상 산란(Flack 변수)**이 필요하고, 가벼운 원자만 있는 화합물(C, H, O)은 Cu Kα를 써도 어려움. [G]
- 유기 실험 2의 생성물은 **라세미 혼합물**로 예상된다고 매뉴얼에 적혀 있음. [M-유기 p8] → [추론] 결정은 중심대칭 공간군(예: P2₁/c)일 가능성이 높음. handout에는 공간군 정보가 없음. [X]

### 8.8 밀도 계산
- **ρ = Z·M / (N_A·V)**. 단위 환산: M(g/mol), V(Å³)이면 **ρ(g/cm³) = Z·M / (0.602214 × V)**. [G] (1 Å³ = 10⁻²⁴ cm³, N_A = 6.02214×10²³)
- 예제 1 (페로센): M = 186.04, Z = 2, V ≈ 410 Å³ (상온 단사정계의 문헌 전형값, [G])
  ρ = 2 × 186.04 / (0.602214 × 410) = 372.08 / 246.9 = **1.51 g/cm³**. 문헌 밀도 약 1.49(상온 근처)와 일치.
- 예제 2 (Aldol-DA 생성물, **가정값**): handout에 셀 정보가 없으므로 V = 2800 Å³, Z = 4를 가정. M = 488.6 (C₃₇H₂₈O, 핸드아웃은 488.59). ρ = 4 × 488.6 / (0.602214 × 2800) = 1954.4 / 1686.2 = **1.16 g/cm³**. 이는 유기 결정의 전형 범위(1.1~1.4)에 든다. [G]
- **검산용 상식**: 유기 분자 결정 ρ ≈ 1.1~1.5, 유기금속(무거운 원자) ≈ 1.3~2.5, 단위세포 안 비수소 원자당 부피 ≈ 18 Å³. 계산값이 이 범위를 크게 벗어나면 **Z를 잘못** 잡은 것. [G]
- 거꾸로 **Z = ρ·N_A·V / M**으로 Z를 정수로 맞추는 문제도 가능.

### 8.9 Miller 지수, 면간 거리, Bragg 법칙
- **Miller 지수 (hkl)**: 결정면이 a, b, c축을 자르는 절편의 **역수를 정수비로 만든 것**. 예: a축을 1/2에서 자르고 b, c축과는 평행하면 절편 (1/2, ∞, ∞) → 역수 (2, 0, 0)이므로 (200)면. (hkl)면 집합의 **면간 거리 d_hkl**은 직교 격자(α=β=γ=90°)에서 1/d² = h²/a² + k²/b² + l²/c². 입방정계는 d = a/√(h²+k²+l²). [G]
- **Bragg 법칙: nλ = 2d sinθ**. 평행한 면들에서 반사된 X선의 경로차가 파장의 정수배일 때만 보강 간섭. **검출기에서 재는 각은 2θ**임에 주의. [G]
- 사용 선원: **Cu Kα λ = 1.5418 Å**, **Mo Kα λ = 0.7107 Å**. 유기 단결정에는 Cu(약한 산란체에 유리), 무거운 원자와 높은 분해능에는 Mo가 일반적. [G]
- 예제 3: d = 2.0 Å인 면, n = 1.
  Cu Kα: sinθ = 1.5418/(2×2.0) = 0.3855 → θ = **22.7°**, 2θ = **45.3°**.
  Mo Kα: sinθ = 0.7107/4.0 = 0.1777 → θ = **10.2°**, 2θ = **20.5°**.
  → 같은 면이라도 **파장이 짧을수록 회절각이 작다**.
- 예제 4 (입방정 NaCl, a = 5.640 Å, Cu Kα): d₂₀₀ = a/2 = 2.820 Å → sinθ = 1.5418/(2×2.820) = 0.2734 → θ = **15.9°**, 2θ = 31.7°.
- **분해능(resolution)**: 가장 작은 측정 d (= λ/(2 sinθmax)). 0.84 Å 분해능을 얻는 데 필요한 θmax는 Mo에서 **25.0°**, Cu에서 **66.6°**. [G] 소분자 구조는 보통 **d ≤ 0.84 Å**(Mo 2θ ≈ 50°)까지 측정.
- **소멸 규칙(systematic absences)**: 중심화 격자와 나사축, 미끄럼면 때문에 **특정 지수의 반사 세기가 0**이 되는 규칙(예: I 격자는 h+k+l이 홀수이면 소멸, C 격자는 h+k 홀수 소멸, P2₁/c는 0k0에서 k 홀수, h0l에서 l 홀수 소멸). 이것으로 **공간군을 정함**. [G]

## 9. 단결정 X선 회절 실험의 흐름 [X + G]

### 9.1 결정 성장 (가장 큰 병목) [G]
| 방법 | 원리 | 비고 |
|---|---|---|
| 느린 증발(slow evaporation) | 용액 용매가 서서히 날아가 과포화 | 가장 쉬움. 구멍 뚫은 마개나 느슨한 뚜껑 |
| 냉각(slow cooling) | 온도에 따른 용해도 차이 | 유기 실험 2의 재결정과 같은 원리 [M-유기 p11] |
| 증기 확산(vapour diffusion) | 안용매가 증기로 천천히 용액에 들어가 용해도를 낮춤 | 소량 시료, 무기, 유기금속에 많이 씀 |
| 용매 층 쌓기(layering) | 두 용매의 경계에서 확산 | |
| 승화(sublimation) | 휘발성 고체가 차가운 면에 기상에서 결정화 | 페로센 정제와 같은 원리 [M-무기 p19] |
- **용매 선택이 중요한 이유**: 용해도가 중간 정도여야 천천히 결정이 자람. 너무 잘 녹으면 결정이 안 생기고, 너무 안 녹으면 분말로 빨리 침전. 용매가 결정 안으로 들어가(용매화물) 격자를 바꾸거나 **무질서**를 일으킬 수도 있음. [G]
- **빠른 침전 = 작고 나쁜 결정**(분말, 쌍정, 응집). 시료가 방해받지 않는 곳에서 **천천히** 자라야 함. [G]
- 크기: handout은 **모서리 0.1~0.3 mm의 "완전한" 단결정**이라고 서술. [X p2]

### 9.2 결정 선택과 마운팅
- 현미경(편광)에서 **투명하고 균질하며 갈라지지 않은** 결정 하나를 고름. 편광을 돌릴 때 한꺼번에 어두워지면 단결정일 가능성이 큼. [G]
- handout 절차: 가는 **유리 섬유나 모세관**(핸드아웃의 예는 지름 0.1 mm 유리 모세관 끝)에 붙이고 **황동 핀**에 고정한 뒤 **고니오미터(goniometer)**에 장착. 고니오미터는 X선 빔 속에서 결정을 3차원으로 정밀하게 회전시킴. [X p2]
- 현대 관행은 **오일(perfluoropolyether 등)에 담근 뒤 나일론 고리(loop)로 건져 냉각 질소 기류에 얼림**. [G] (handout은 섬유/모세관 방식을 서술)
- **저온(100~173 K) 측정의 이유**: (1) 열진동 감소로 고각 반사의 세기가 증가, 분해능 향상, (2) 결정이 **방사선 손상과 용매 손실**에서 보호됨, (3) 타원체가 작아져 **무질서를 풀기 쉬움**, (4) 수소 원자 위치 개선. 이 handout의 측정 온도는 **173(2) K**. [X p3]

### 9.3 데이터 수집
- **회절계(diffractometer)** = X선 발생기 + 고니오미터 + 검출기. handout의 장비는 **CCD 면 검출기(Bruker SMART)**. 필름이나 검출기가 회절 무늬를 기록. [X p2-3]
- 결정을 조금씩(예: 0.3~1°) 돌리며 **수백~수천 장의 프레임(frame)** 을 찍음. 각 프레임에 여러 반사(reflection)가 나타남. [G]
- 품질 용어:
| 용어 | 의미 |
|---|---|
| **중복도(redundancy, multiplicity)** | 같은 (대칭 동등) 반사를 측정한 횟수. 높을수록 오차 평균, 흡수 보정에 유리 |
| **완전도(completeness)** | 주어진 분해능까지 이론상 가능한 독립 반사 중 측정된 비율. 보통 ≥ 99% 요구 |
| **분해능(resolution)** | 8.9절. 작을수록 원자가 선명 |

### 9.4 단위세포 결정과 지수화(indexing)
- 처음 몇 십 프레임에서 **반사 위치**를 찾고, 이를 **역격자**로 해석해 **단위세포(a, b, c, α, β, γ)와 방향 행렬**을 정함. 이 단계를 **지수화**라고 하며 **결정이 단결정이 아닌 경우(쌍정, 다결정)에는 설명이 안 됨**. [G]
- 이 단계에서 **브라베 격자형(P/C/I/F)과 결정계 후보**가 나옴. [G]

### 9.5 적분, 스케일링, 흡수 보정
- 모든 프레임에서 각 반사의 **적분 세기 I와 불확도 σ(I)**를 구함(적분). 프레임 사이의 선원 세기 차이를 맞춤(스케일링). [G]
- **흡수 보정(absorption correction)**: 결정이 X선을 흡수하는 정도는 방향에 따라 다름(특히 Cu, 무거운 원자). 중복 측정을 이용한 **다중 스캔(multi-scan)** 보정이 흔함. 유기 C/H/O 화합물은 흡수가 작아 영향이 작음. [G]
- 대칭 동등한 반사들의 일치도 **R_int**(약 2~8%)가 데이터 질의 척도. [G]

### 9.6 공간군 결정
- (1) **결정계와 격자형**(단위세포에서), (2) **소멸 규칙**(8.9)과 (3) **세기 통계**(중심대칭이면 세기 분포가 달라짐)로 후보 공간군을 좁힘. 때로 P2₁/c처럼 하나로 유일하게 정해지고, 때로는 몇 가지가 남아 **구조가 풀리는지**로 판단. [G]

### 9.7 구조 풀기: 위상 문제
- 측정되는 것은 **세기 I ∝ |F|²**뿐이고 **위상**은 잃음 → **위상 문제(phase problem)**. [G]
| 방법 | 설명 | 적합 |
|---|---|---|
| **직접법(direct methods)** | 구조 인자 사이의 통계적 관계로 위상 추정 | 소분자(유기물) 표준 |
| **고유 위상법(intrinsic phasing)** (SHELXT) | 위상을 반복 정련하는 현대 방법 | 소분자 표준 |
| **패터슨법(Patterson)** | \|F\|²의 푸리에 변환 = 원자간 벡터 지도, 무거운 원자 위치를 먼저 찾음 | **무거운 원자(Ru, Fe)** 포함 구조 |
- 이후 푸리에 지도에서 **전자 밀도 봉우리**를 원자로 배정하고 나머지 원자는 차 푸리에 지도로 찾음. [G]

### 9.8 정련(refinement)
- **F²에 대한 최소제곱법(least squares on F²)**(SHELXL): 계산한 |F_c|²이 관측한 |F_o|²와 가장 잘 맞도록 **원자 좌표, 이방성 변위 매개변수(ADP)**를 조절. [G]
- 비수소 원자는 보통 **이방성**(타원체)으로, 수소는 **등방성 + 승마 모델(riding model)**로 다룸.
- **수소 원자 처리**: X선은 **전자**를 보는데 H는 전자가 하나뿐이고 결합 쪽으로 쏠려 있어 **위치가 부정확하고 X–H 길이가 실제(핵 위치)보다 짧게** 나옴. 그래서 H를 **기하학적으로 계산한 위치**에 놓고 부모 C 원자를 따라 움직이게(riding) 함. **C–H 거리는 온도와 혼성에 따라 표준값으로 고정**: 방향족 **0.95 Å**, CH₂ **0.99 Å**, CH **1.00 Å**(173 K 근처). [G]
- **handout의 C–H 값이 바로 이것**: C(17)–H(17A) **0.9500**(방향족), C(19)–H(19A) **0.9500**, C(7)–H(7A) **0.9900**(CH₂), C(6)–H(6A) **1.0000**(CH). 표준 편차(괄호)가 **없는** 것도 "고정된 값"이라는 표시. [X p3; 해석은 G]. → **수소가 들어간 결합 길이는 실험값이 아니라 모델값**이라는 점이 함정 문제가 될 수 있음.
- 다른 C–C, C=O 값에는 **(16), (2) 같은 괄호**가 있고 이는 **마지막 자리의 불확도**: 1.2002(16) = 1.2002 ± 0.0016 Å. [G]

### 9.9 품질 지표
| 지표 | 의미 | 좋은 값 |
|---|---|---|
| **R1** | (Σ \|\|F_o\|−\|F_c\|\|)/Σ\|F_o\|, 관측 반사에 대한 모델과 데이터의 일치. 보통 I > 2σ(I)만 사용 | 소분자 **< 5%**(0.05). 5~8% 보통, > 10% 의심 |
| **wR2** | F²에 가중치를 둔 모든 반사의 R | **< 12~15%**. R1의 약 2~3배 |
| **GOF (S)** | 적합도 = √[Σw(F_o²−F_c²)²/(n−p)], 가중치와 모델의 적절함 | **≈ 1.0** (0.9~1.2). ≫ 1이면 모델 부족 또는 σ 과소평가 |
| **잔여 전자 밀도(residual density)** | 차 푸리에 지도의 최대, 최소 봉우리 (e/Å³) | 소분자 **\|Δρ\| < 0.5 e/Å³**, 무거운 원자 근처는 크게 나올 수 있음 |
| **R_int** | 대칭 동등한 반사의 일치도 | 약 2~8% |
| **분해능, 완전도** | 데이터 범위 | d ≤ 0.84 Å 근처, ≥ 99% |
| **결합 길이 불확도** | 괄호 안 숫자 | C–C ≈ 0.002~0.005 Å 정도면 좋음 |
| **Flack 변수** | 절대 배치(키랄 공간군) | 0(±0.1)이면 맞음, 0.5면 라세미 쌍정 |
- **R1이 작아도 구조가 틀릴 수 있음**(원자 종류 오배정, 잘못된 공간군). 항상 **화학적으로 말이 되는지** 확인. [G]

### 9.10 열적 타원체(ORTEP)
- **ORTEP**(Oak Ridge Thermal Ellipsoid Plot): 각 원자를 **이방성 변위 타원체**로 그림. handout은 "타원체의 모양과 크기는 **각 원자의 진동 운동**과 **원자의 전자 밀도를 찾을 확률**을 나타낸다"고 설명. [X p3]
- 이 그림은 **50% probability ellipsoids**: 원자 핵이 **타원체 안에 있을 확률이 50%**가 되게 그린 것. [X p2 그림 1] (30%, 50%, 90% 중 하나로 표기해야 함)
- 읽는 법: [G]
| 관찰 | 의미 |
|---|---|
| 작고 둥근 타원체 | 단단히 고정, 진동 작음. 구조 중심부, 무거운 원자 |
| 큰 타원체 | 진동이 큼(말단 원자, 저온이 아님) 또는 **약한 무질서** |
| **한 방향으로 길쭉한** 타원체(담배 모양) | 그 방향으로 큰 진동 또는 **두 위치에 걸친 무질서**. 특히 **결합에 수직**으로 납작/길쭉하면 고리의 비틀림 진동 |
| 비정상적으로 작거나(음의 값) 납작한 타원체 | 원자 종류 오배정, 흡수 보정 부족, 모델 오류 |
- handout 그림에서 **말단 페닐(C11–C13, C16–C19, C33–C37)** 쪽 원자는 **내부의 다리 머리 탄소보다 타원체가 큰 경향**이 있음. [X p2 그림 1, 눈으로 본 판단이므로 [추론]]

### 9.11 무질서(disorder)와 occupancy
- **무질서**: 결정 안에서 어떤 부분(고리, 용매, 이온)이 **두 가지 이상의 위치나 방향**을 취함(정적: 결정마다 다름, 동적: 시간에 따라 움직임). 단위세포 평균이므로 **원자가 겹쳐 보임**. [G]
- 모델링: 각 위치에 **점유율(occupancy, 합 = 1)**을 정련(예: 0.62/0.38) + 기하 제약. 점유율이 0.5이면 두 위치가 똑같이 있음. [G]
- 전형적 무질서: **CF₃, 페닐 회전, tert-부틸, 용매 분자, 상온 페로센의 Cp 고리**(11절). 저온 측정이 해결에 도움. [G]

### 9.12 CIF와 checkCIF
- **CIF(Crystallographic Information File)**: 결정 데이터, 셀, 공간군, 좌표, 결합 길이, 각도, 정련 결과를 담은 표준 텍스트 파일. 거대 분자용은 mmCIF. Mercury, ChemBio3D, Jmol 등으로 열어 3차원으로 봄. [X p2]
- **checkCIF**(IUCr 서버): CIF를 자동 검사해 **A~G 경고(alert)**를 냄. 높은 경고는 **공간군 오류, 오배정 원자, 빠진 대칭, 큰 잔여 밀도, 설명되지 않은 용매 구멍** 등을 알림. 결과를 **논문, CSD 기탁 전**에 해명해야 함. [G]
- **CSD(Cambridge Structural Database)**: 소분자 결정구조 데이터베이스. 비교용 평균 결합 길이의 출처. [G]

- **다리 케톤 C2–C1–C5 = 99.0°**: 일반 케톤 C–C(=O)–C ≈ 116~120°보다 훨씬 작음. 이 **고리 변형**이 C=O 신축을 **높은 진동수(1773 cm⁻¹, 일반 케톤 약 1715)**로 올리는 이유라고 설명. [R-DA 3.2; IR 해석은 설명용]
- 시험 팁: **각이 120°에서 크게 벗어나도 sp²일 수 있다**(고리 변형). 판정은 **합이 360°인가**로.

### 10.5 endo와 exo 구별 [X + 추론]
- **정의**(노보넨 유형 이환): 새로 붙은 치환기(여기서는 **C6의 페닐 C32**)가 **C=O 다리(C1) 쪽(syn)**이면 **exo**, **C3=C4 알켄 쪽(anti to C=O 다리)**이면 **endo**. (보고서의 표현: "styrene 페닐이 카보닐 다리의 anti, C3=C4 다리와 같은 쪽 = endo"). [R-DA 3.2; L2 p6-8 일반 개념]
- 그림 1에서 C32 페닐은 O1/C1(그림 위쪽)에서 **먼 쪽, 알켄 C3=C4 아래쪽**으로 뻗어 있음. [X 그림 1, 눈으로 본 판단이므로 [추론]] 사용자 보고서는 **endo 부가물 3A**로 결론. [R-DA 3.2] **handout 자체는 어느 이성질체인지 쓰지 않음.**
- **정량적으로 확인하는 법**(시험에서 좌표나 표가 더 주어질 때): [G]
  1. **C32–C6–C5–C1(또는 C32–C6–C5–C4) 비틀림각**: 페닐이 C1(다리)과 같은 쪽이면 C1을 포함한 비틀림각의 절댓값이 작고, 알켄 쪽이면 C4를 포함한 쪽이 작음(정확한 값은 자료에 없음). 두 값을 비교해 **어느 쪽이 작은지**로 판단.
  2. **C32…C1 거리와 C32…C3(또는 C4) 거리**: 가까운 쪽이 syn 쪽.
  3. **C6의 H6A와 C=O 다리의 위치**: exo-H이면 H6A가 C1 쪽을 향함.
- **handout의 비틀림각은 endo/exo를 직접 구별하지 못함**: H6A–C6–C7–H7A = −12.60°는 **H6A와 H7A가 거의 겹침(eclipsed, cis)**을, H6A–C6–C7–H7B = 133.30°는 **trans**를 뜻함. 단단한 이환 구조에서는 **endo-endo 수소 쌍과 exo-exo 수소 쌍 둘 다 cis(약 0°)**이므로 이 값만으로는 endo/exo를 결정할 수 없고, **H와 다리의 상대 위치(다른 비틀림각)**가 필요. [G + 추론]
- **NMR과 연결**: Karplus 관계로 cis(≈0°) → J 큼(10.0 Hz), trans(≈133°) → J 작음(6.5 Hz). 그래서 **H6A(Ha) – H7A(Hb) cis, H7B(Hc) trans**로 배정. [R-DA 3.2; M-유기 p9] 하지만 3A/3B 모두 cis 하나, trans 하나이므로 **NMR의 J로는 endo/exo를 못 가름 → X선 필요**. [R-DA 3.2]
- **kinetic/thermodynamic 해석**: endo 부가물은 **더 빨리 생기지만 열역학적으로 덜 안정**(kinetic). 높은 온도에서는 exo가 우세할 수 있음. [L2 p8] 다만 tetracyclone의 네 페닐기가 입체 방해로 endo 접근을 막을 수도 있어 일반 규칙만으로 단정할 수 없음. [`organic/02` 1.3절의 초안 주석]

### 10.8 예상 문제 3개와 모범 답안
**Q1. handout의 결합 길이로 C3–C4가 이중결합임을 설명하라.**
A. C3–C4 = **1.356(2) Å**로 C=C 이중결합의 전형값(1.33~1.34 Å)에 가깝고 sp³–sp³ 단일결합(1.54 Å)이나 방향족(1.39~1.40 Å)보다 짧다. 주변 C2–C3(1.539), C3–C14(1.484)는 단일결합. C3, C4 각의 합이 약 360°라서 평면 sp². [X p3]

**Q2. 생성물이 탈카보닐 화합물이 아니라 다리 케톤임을 X선 자료에서 어떻게 아는가?**
A. 화학식이 **C₃₇H₂₈O**(산소 1개)이고 O1–C1 = **1.2002(16) Å**으로 C=O 결합 길이. C1의 세 각이 131.47 + 129.52 + 99.00 = **360.0°**로 평면 sp² 카보닐 탄소이며, C2–C1–C5가 99°로 줄어든 것이 **노보넨형 다리의 변형**을 보인다. 탈카보닐 생성물 4(C₃₆H₂₈)에는 C=O가 없다. [X p3; M-유기 p8]

**Q3. H6A–C6–C7–H7A = −12.60°, H6A–C6–C7–H7B = 133.30°가 뜻하는 것과 한계는?**
A. H6A와 H7A는 **거의 eclipsed(cis, 비틀림각 약 0°)**, H6A와 H7B는 **trans(약 133°)**이다. 이환 틀 안에서 고리가 고정되어 있으므로 cis 쌍은 Karplus 관계로 큰 J(10.0 Hz), trans 쌍은 작은 J(6.5 Hz)를 준다. 그러나 endo, exo 둘 다 cis 쌍 하나와 trans 쌍 하나를 가지므로 **이 두 값만으로 endo/exo를 구별할 수 없고**, C6의 페닐이 C=O 다리 쪽인가 알켄 쪽인가를 보여 주는 **구조 그림이나 다른 비틀림각**이 필요하다. [X p3; R-DA 3.2]

## 12. RuCl₂(PPh₃)₃ 결정구조 심화 [M-무기 p3 + G]

### 12.1 문헌 사실 [M-무기 p3]
- **La Placa와 Ibers, Inorg. Chem. 1965, 4, 778**. 시료는 Vaska가 준비. Ru(II)는 **5배위**, **반자성**, **단량체**. Ru는 **찌그러진 사각뿔**의 중심 쪽에 있고 **밑면에 trans Cl 두 개와 trans P 두 개, 꼭짓점에 P 하나**. [M-무기 p3]

### 12.2 세부 구조 [G, 문헌 기억 기반이며 정확한 값은 자료에 없음]
- **여섯 번째 자리**(꼭짓점 P의 반대쪽)는 **비어 있음**. 그러나 **한 PPh₃ 페닐 고리의 ortho C–H가 이 자리를 막고** 있어 Ru…H 거리가 **약 2.59 Å**(van der Waals 접촉보다 훨씬 가까운 **아고스틱형 약한 상호작용**). 이것이 위 2절의 "PPh₃ 하나가 배위 자리를 막는다"는 강의 슬라이드 필기와 일치하는 설명이며, 2절에서 "자료에서 확인되지 않음"이라 한 아고스틱 상호작용 내용을 [G]로 보완한다.
- 이 5배위 16전자 착물은 **실제로는 "거의 6배위"**로 볼 수 있음. 사각뿔 꼭짓점 반대쪽으로 **기하 구조가 팔면체에 가까움**. [G]
- **결합 길이 경향**(문헌 전형값, [G]): **꼭짓점 Ru–P ≈ 2.23 Å**(**짧음**), **밑면 Ru–P ≈ 2.37~2.41 Å**(**김**), **Ru–Cl ≈ 2.39 Å**. 
  - 꼭짓점 P가 짧은 이유(추론): 꼭짓점 P의 **trans 쪽에 리간드가 없어** trans 영향(길게 하는 효과)이 없고 입체 혼잡도 밑면보다 작음. 밑면 P 둘은 **서로 trans**이고 부피가 큰 PPh₃끼리 마주 보고 있어 **길어짐**. [추론]
  - 밑면 P–Ru–P와 Cl–Ru–Cl은 **180°에서 벗어남**(밑면이 꼭짓점 반대쪽으로 구부러진 사각뿔). 값은 자료에 없음. [G]
- **주의**: 위 7절은 용액에서 **꼭짓점 포스핀이 쉽게 해리**한다고 적는다. 결정에서 꼭짓점 Ru–P가 **짧다**는 사실과 어떻게 양립하는지는 자료에 없고 [추론: 해리하는 PPh₃가 어느 것인지는 단정하지 말 것]. 시험에서는 "결정 구조에서 구별되는 P 자리가 있다"까지만 말하는 것이 안전.

### 12.3 촉매와의 연결 [M-무기 p4; G]
- **빈 자리**: 기질(알켄, H₂, 알코올)이 결합할 **배위 자리**. 16전자 착물은 **18전자로 가려는 경향**이 있어 반응성이 큼. [G]
- 페닐 ortho-H의 **약한 점유**는 자리를 어느 정도 가리지만 **쉽게 밀려남**(약한 결합)이라 촉매에 유리. [추론]
- 활성종은 hydride(RuH₂(PPh₃)₃ 등)로 제안. [M-무기 p4]

### 12.4 전자 수와 자기적 성질
- CBC: RuL₃X₂ → Ru 8 + L 3×2 + X 2×1 = **16전자**. 산화수 +2, **d⁶**. [M-무기 p3; `03` 5.4]
- **반자성**: 사각뿔 장에서 d⁶의 6개 전자가 **모두 쌍을 이룸(저스핀)**. 일반적으로 **5배위 사각뿔 d⁶ 저스핀**은 반자성. [M-무기 p3에서 반자성만 확인됨, 설명은 G + 추론]
- 비교: **페로센**은 18전자 반자성(d⁶ 저스핀, 6배위). 두 화합물 모두 d⁶ 반자성이라는 공통점이 있음.

## 13. 결정학 문제 유형별 풀이 전략

### 13.1 CIF 표가 주어질 때 (셀, 공간군, Z)
1. **결정계 확인**: 각이 모두 90°이면 사방정 이상, β만 다르면 단사정, 모두 다르면 삼사정.
2. **부피 V** 계산: 사방정이면 abc, 단사정이면 abc·sinβ. (예: a=10.0, b=12.0, c=25.0 Å, β=100° → V = 3000·sin100° = 3000×0.9848 = **2954 Å³**)
3. **밀도** ρ = Z·M/(0.602214·V). 상식 범위(유기 1.1~1.5)와 비교(8.8).
4. **Z′** = Z / (공간군 일반 위치 수). P2₁/c는 4, P-1은 2, C2/c는 8, P2₁2₁2₁은 4. Z′ < 1이면 분자가 **특수 위치(대칭 요소 위)**에 있음.
5. **키랄성**: 공간군에 **반전 중심, 거울면, 미끄럼면이 있는가**. 있으면 **중심대칭**이므로 거울상 순수 결정이 될 수 없음 → 라세미체 또는 achiral 분자. P2₁2₁2₁이면 **거울상 순수**하거나 자발 분할.
6. 부피로 원자 수 검산: **V/Z ≈ 18 Å³ × (비수소 원자 수)** 근사. 예: C₃₇H₂₈O는 38 원자 → 약 680 Å³, Z=4이면 V ≈ 2700 Å³ → 위 예제 2와 비슷. [G]

### 13.2 ORTEP 그림이 주어질 때 읽을 것
1. 원자 번호표와 **원소 종류**(색, 이름)로 **연결 관계(connectivity)** 확인.
2. 타원체의 **확률 수준**(보통 50%)과 크기 비교(큰 것 = 말단, 무질서).
3. **다리 원자, 이중결합** 위치.
4. **입체화학**: 치환기가 환의 어느 쪽, 다리에 대해 syn/anti, endo/exo, cis/trans.
5. **대칭**: 분자의 대칭 요소(거울면, 반전 중심, 2회축)가 있는가.
6. **수소**가 그려져 있는가(대개 생략 또는 구형).
7. 분자 **형태(conformation)**(예: eclipsed, staggered, boat, chair).

### 13.3 결합 길이가 주어질 때
- **1.20 C=O, 1.34 C=C, 1.39 방향족, 1.48 sp²–sp² 단일, 1.51 sp³–sp² 단일, 1.54 sp³–sp³ 단일**. (C≡C는 약 1.20이며 C=O와 값이 겹치므로 화학식과 문맥으로 구분.) [G]
- 금속 결합: **M–L 길이는 금속과 리간드의 크기, 산화수, trans 영향**에 의존. **같은 종류가 자리에 따라 다르면 환경 차이**. [G]
- **고리 변형**(작은 각, 긴 결합)을 놓치지 말 것(10.4).

### 13.4 두 형태(conformer)가 주어질 때
- "결정에서는 어느 형태이고, 용액에서는 다를 수 있는 이유"를 묻는다면: 결정은 **packing 힘(분자간 접촉, 에너지 최소 한 형태)**이 고르며, 용액은 **형태 사이의 빠른 평형**이어서 **NMR에서 평균**된다. 에너지 차가 작은 경우(예: 페로센 4 kJ/mol) 결정 환경이 쉽게 형태를 바꾼다. [G]
- 페로센: 기체 eclipsed, 상온 결정 staggered(평균), 저온 결정 거의 eclipsed. [11.2]

### 13.5 전형적 함정 답안
| 함정 | 올바른 서술 |
|---|---|
| "결정 구조는 시료 전체의 구조를 보여 준다" | **그 결정 하나**의 구조. 벌크 순도는 NMR, mp, 원소분석으로 |
| "NMR이 하나의 신호이므로 X선에서도 모든 C–H가 같은 길이" | 결정에서는 **고정된 모델값**과 대칭 차이가 있을 수 있음 |
| "각이 120°에서 벗어나면 sp²가 아니다" | **각의 합이 360°**인지 확인. 고리 변형이 있음 |
| "C–H 길이는 정확히 측정된다" | **X선은 H의 핵 위치를 못 봄**, riding model 고정값(0.95/0.99/1.00 Å) |
| "큰 타원체 = 구조 오류" | 말단이나 무질서에서 정상 |
| "R1이 작으면 구조가 맞다" | 화학적으로 타당한지 확인 |
| "페로센은 결정에서 항상 eclipsed (또는 staggered)" | **상, 온도 의존**. 상온 결정은 staggered(무질서), 기체는 eclipsed |
| "torsion −12.6° → endo" | cis/trans만 알려 줌. endo/exo는 **다리와의 상대 위치** |
| "승화물이 바늘이므로 단사정계" | habit ≠ 결정계 |
| "RuCl₂(PPh₃)₃는 6배위" | **5배위**(찌그러진 사각뿔). 여섯 번째 자리는 ortho-H가 약하게 가림 |
| "라세미체이므로 결정이 키랄 공간군" | 라세미체는 대개 **중심대칭** 공간군 |

## 14. 추가 연습 문제 (정답 포함)

1. 다음 중 **키랄(Sohncke) 공간군**을 모두 고르라: P2₁/c, P-1, P2₁2₁2₁, C2/c, P2₁.
   **P2₁2₁2₁과 P2₁.** (나머지는 반전 중심 또는 미끄럼면이 있음) [G]
2. 단사정 P2₁/c 결정에서 Z = 4이면 Z′는? 분자가 반전 중심 위에 있다면 Z는?
   **일반 위치가 4개이므로 Z′ = 1. 분자가 반전 중심 위에 있으면 Z′ = 0.5이므로 Z = 2.** [G]
3. 셀 부피 V = 1500 Å³, Z = 4, M = 360 g/mol인 결정의 밀도는?
   **ρ = 4×360/(0.602214×1500) = 1440/903.3 = 1.59 g/cm³.** 단위: M g/mol, V Å³ 때 0.602214 사용. [G]
4. Mo Kα(0.7107 Å)에서 d = 1.00 Å인 반사의 θ와 2θ는? Cu Kα(1.5418 Å)에서는?
   **Mo: sinθ = 0.3554 → θ = 20.8°, 2θ = 41.6°. Cu: sinθ = 0.7709 → θ = 50.4°, 2θ = 100.9°.** [G]
5. Cu Kα로 측정할 때 d = 0.75 Å보다 작은 면을 볼 수 있는가?
   **sinθ = 1.5418/(2×0.75) = 1.028 > 1이므로 불가능. 한계는 d = λ/2 = 0.77 Å.** [G]
6. handout에서 C1의 세 각(131.47, 129.52, 99.00°)의 합과 그 뜻은?
   **합 = 360.0°로 평면 sp² 카보닐 탄소. C2–C1–C5가 99°인 것은 이환 다리의 변형.** [X p3]
7. handout에서 결합 길이 0.9500, 0.9900, 1.0000 Å의 공통점은 무엇이고 왜 중요한가?
   **모두 C–H이고 표준 편차가 없다. riding model로 고정된 값(방향족 0.95, CH₂ 0.99, CH 1.00 Å)이라 실험으로 얻은 값이 아님. H 위치 판정에 의존하면 안 됨.** [X p3 + G]
8. handout의 화학식 C₃₇H₂₈O와 FW 488.59가 생성물을 어떻게 한정하는가?
   **tetracyclone(C₂₉H₂₀O) + styrene(C₈H₈) = C₃₇H₂₈O이므로 1:1 부가물이고 산소가 남아 있어 탈카보닐(C₃₆H₂₈, 4)이 아니다.** [X p3; M-유기 p8]
9. X선 구조로 endo/exo를 구별하는 방법과, NMR의 J 값이 구별을 못 하는 이유는?
   **X선: styrene 유래 페닐이 C=O 다리와 같은 쪽(exo)인지 알켄 C3=C4 쪽(endo)인지 3차원 위치로 확인. NMR: 두 이성질체 모두 CH₂ 수소 하나는 CHPh와 cis, 하나는 trans이라 J(약 10, 6.5 Hz)가 같은 패턴.** [R-DA 3.2; M-유기 p9]
10. 상온 단사정 페로센 결정(Z = 2)에서 분자의 대칭 위치와 이것이 staggered 형태와 어떻게 연결되는가?
    **Z = 2이고 P2₁/a의 일반 위치가 4개라 Z′ = 0.5, 분자가 반전 중심 위에 있다. 반전 중심은 D₅d(staggered)와 일치. 고리는 무질서하며 평균 구조가 staggered로 보임.** [G]
11. 페로센의 결정 상태에서 고리 무질서가 저온에서 사라지는 이유를 설명하라.
    **회전 장벽이 약 4 kJ/mol로 낮아 상온에서는 고리가 여러 방향을 취하지만, 약 164 K 아래에서는 열에너지가 장벽보다 작아져 한 배향으로 고정(질서화, 삼사정계로 상전이).** [G]
12. RuCl₂(PPh₃)₃에서 꼭짓점 Ru–P가 밑면 Ru–P보다 짧은 이유와 ortho-H의 역할을 쓰라.
    **꼭짓점 P는 trans 자리가 비어 있어 trans 영향을 받지 않고 입체 혼잡도 적어 짧다(약 2.23 대 2.37~2.41 Å, [G]). 빈 여섯 번째 자리를 페닐 ortho C–H가 약하게 점유(Ru…H 약 2.59 Å)해 사실상 6배위처럼 보이나, 약한 상호작용이라 촉매 반응에서 기질이 쉽게 밀어낼 수 있다.** [G + 추론]
13. (추가) 사진 batch-2_60um의 바늘이 폭 약 3 µm이다. 일반 실험실 단결정 XRD에 적합한가?
    **아니오. 권장 크기 0.1~0.3 mm [X p2]보다 훨씬 작고, 가늘어 산란 체적이 작다. 더 큰 결정을 키우거나 분말 XRD를 쓴다.** [추론]
