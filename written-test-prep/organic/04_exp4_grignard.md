# 유기 실험 4: Grignard 반응으로 (±)-linalool 합성 (Schlenk line, 컬럼)

출처 규칙은 `../README.md` 참고. 절차와 수치는 AY26/27 유기 매뉴얼 [M-유기 p19-27]이고, 해석은 저장소의 보고서 초안 `organic/4/CM3191 Organic Expt 4 Grignard Report Draft.pdf`(.tex)에서 가져와 [초안]으로 표시했습니다. 초안의 "예상 IR/NMR 값"은 구조에서 예상한 대략적인 값이지 측정값이 아닙니다. 준비 자료로 `organic/CM3191 Organic Schlenk Line Prep.pdf`도 있습니다.

## 1. 반응과 개념

- **6-methyl-5-hepten-2-one** (MW 126.20, 밀도 0.855 g/mL) + **vinylmagnesium bromide** (1 M THF 용액) → **(±)-linalool** (MW 154.25), 질소 분위기, 무수 조건. [M p19-20]
- Grignard 시약 R-MgX: R은 알킬 또는 아릴, X는 할로젠(주로 Cl, Br, I). **C-Mg 결합은 극성이 매우 커서 탄소가 강한 친핵체**. 카보닐 탄소는 분극으로 **친전자성**. Victor Grignard는 **1912년 노벨 화학상**. [M p19]
- Grignard 시약과 카보닐의 반응 생성물: CO₂ → **카복실산**, 알데하이드 → **2차 알코올**, 케톤과 에스터 → **3차 알코올**. [M p19]
- linalool은 **3차 알코올(monoterpene)**로 200종 이상의 식물 정유에서 발견(Lavandula, Coriandrum, Cinnamomum 속). **(S)-linalool은 고수 정유**의 주성분, **(R)-linalool은 라벤더 정유**에 있음. [M p19]
- 케톤과 Grignard 시약이 모두 achiral이고 카보닐 탄소가 prochiral이므로 두 면의 공격 확률이 같아 **라셈(±)** 생성. 광학 회전은 0. [초안]
- Grignard 시약은 **강한 염기**이므로 물과 같은 양성자성 화합물에 의해 즉시 파괴되며 산소와도 반응. vinylmagnesium bromide는 양성자화되면 **ethylene**을 줌. 그래서 **무수 THF, 질소 분위기, 가열 건조한 유리기구**가 필요. [M p20, p23; 초안]
- 과량(**2.5 eq**)을 쓰는 이유: 수분에 의한 손실과 Grignard가 염기로 작용해 케톤을 enolize하는 경쟁 반응을 보상. [초안]

| 시약 | MW | 밀도 | 양 | 몰수 |
|---|---|---|---|---|
| 6-methyl-5-hepten-2-one | 126.20 | 0.855 | 0.44 mL | **3.0 mmol** (0.376 g → 2.98 mmol) |
| vinylmagnesium bromide, 1 M THF | 131.25 | - | 7.5 mL | **7.5 mmol (2.5 eq)** |
| THF | 72.11 | - | 5 mL | 용매 |
| linalool | 154.25 | - | - | 이론 수율 **약 0.46 g** (2.98 mmol × 154.25) |

## 2. 절차

### 2.1 세션 1: 반응 setup [M-유기 p20-23]

**유리기구를 불꽃 건조(Schlenk line)**
- 경고: **열풍기(hot air gun)는 300-500 °C**를 낸다. 가열 중에 흄후드에 **인화성 화학물질이나 용매가 없는지** 반드시 확인.
1. **50 mL 두 목 둥근바닥플라스크**(교반자 포함)의 **곁 목**에 **고무 셉텀**, **수직(가운데) 목**을 Schlenk line의 **stopcock adapter**에 연결한다.
2. 이중 매니폴드(two-way manifold)의 밸브를 **진공**으로 돌리고 **열풍기**로 플라스크를 가열해 잔류 수분을 날린다.
3. 몇 분 식힌 뒤 밸브를 **질소**로 돌린다. (플라스크가 건조되고 불활성 분위기로 채워짐)
4. **한 번 더 반복**: 진공 → 열풍기 가열 → 식힘 → 질소. (총 **2회**)
5. 화학물질을 넣기 전에 플라스크를 **실온**까지 식힌다.

**시약 첨가**
6. **6-methyl-5-hepten-2-one 0.44 mL (3 mmol)**와 **무수 THF 5 mL**를 플라스크에 넣는다. **얼음-물 배스**에서 **5-10분** 식힌다. (바늘 사용 주의)
7. vinylmagnesium bromide 병(1 M THF)은 제조사가 **질소 하에 포장**했으므로 **모든 조작을 질소 분위기**에서 한다. **병을 리토르트 스탠드에 클램프**로 고정하고 **질소(풍선 또는 Schlenk line)** 아래에 둔다.
8. **20 mL 주사기와 긴 바늘**을 **질소로 purge**한다.
9. 주사기로 **Grignard 용액 7.5 mL**를 취한다. **바늘을 병에서 빼기 전에 주사기에 질소를 조금 끌어들인다**(용액을 보호하고 바늘에서 떨어지는 것을 막음).
10. 냉각한 반응 플라스크에 vinylmagnesium bromide를 **한 방울씩(dropwise)** 가한다.
11. 첨가가 끝나면 **얼음-물 배스를 제거**하고 **실온에서 90분** 교반한다.
12. 주사기와 바늘에 남은 Grignard 시약은 **포화 NH₄Cl**로 quench한다. 과량의 Grignard가 NH₄Cl이나 물과 반응해 **ethylene 기체**를 낸다. 이 단계는 **폐기물용 흄후드(waste fumehood)**에서 한다. 사용한 주사기는 **sharp container(바늘통)**에 버린다.

### 2.2 세션 1: 후처리 [M p23-24]
1. Schlenk line 매니폴드 밸브를 **OFF**로 돌리고 플라스크를 분리한다. **고무 셉텀**으로 닫아 자신의 흄후드로 가져온다.
2. **Quenching**: 플라스크를 **얼음-물 배스**에서 식히고 **포화 NH₄Cl 10 mL**를 **한 방울씩** 가한다.
3. **추출**: **물 10 mL**를 가하고 혼합물을 **150 mL 분액깔때기**로 옮긴다. 플라스크를 **ethyl acetate 20 mL**로 헹궈 깔때기에 붓는다.
4. 흔들어 두 층을 분리하고 수용액층과 유기층을 **각각 다른 삼각 플라스크**에 받는다.
5. 수용액층을 분액깔때기에 되돌려 **ethyl acetate 20 mL씩 2번 더** 추출한다(**총 3번**). ethyl acetate 층을 합친다(**약 60 mL**).
6. 합친 유기층을 분액깔때기에서 **brine(포화 NaCl) 15 mL**로 추출하고, 유기층을 건조한 **250 mL 삼각 플라스크**에 받는다.
7. **무수 Na₂SO₄**를 가해 **15분** 둔다.
8. **TLC 분석**: 플레이트에 두 점: 출발 물질(6-methyl-5-hepten-2-one)과 반응 혼합물(Na₂SO₄ 위에서 건조 중인 용액). 전개용매 **hexane : ethyl acetate = 9:1**. **KMnO₄ 용액**으로 염색해 점을 본다. 이 결과는 2주차 컬럼 크로마토그래피에 사용된다.
9. 용액을 **건조하고 질량을 잰 250 mL 둥근바닥플라스크**로 여과한다. **회전증발기**로 용매를 제거해 **조(crude) linalool**을 얻는다.

### 2.3 세션 2 (Week 2): 컬럼 크로마토그래피 [M p24-26]

**준비**
- **컬럼 용리액**: 250 mL 비커에 **hexane : ethyl acetate 9:1을 200 mL** 만든다. **깨끗한 Pasteur 피펫 2개**(시료용, 용리액용) 준비.
- **실리카 겔 슬러리**(주의: 실리카 분말은 흡입하면 **독성**): **흄후드에서** 250 mL 비커 또는 삼각 플라스크에 **용리액 20-30 mL**와 **실리카 겔 약 4 스푼**을 넣고 잘 섞는다.
- **컬럼**: **솜**과 **모래 층**을 넣는다. 흄후드 안 리토르트 스탠드에 고정하고 **100 mL 삼각 플라스크**로 받는다. 용리액 **10 mL**를 넣고 stopcock을 열어 흐름을 확인한다.

**컬럼 packing**
1. 실리카 겔 슬러리를 **고체 깔때기**로 컬럼에 붓는다. 용리액으로 헹궈 실리카를 가라앉힌다. 가라앉은 실리카 컬럼의 길이는 **약 12-15 cm**. 필요하면 **공기 펌프**로 유속을 높인다. 용매가 실리카 바로 위에 올 때까지 뺀다.
2. 실리카 위에 **모래 층(약 0.5 cm)**을 얹고 컬럼을 헹군다. 용매가 실리카 바로 위까지 오도록 뺀다.

**시료 loading**
3. **긴 Pasteur 피펫**으로 조 반응 혼합물을 컬럼에 옮긴다. stopcock을 열어 실리카에 흡수시킨다.
4. **Rinsing 1**: 둥근바닥플라스크에 용리액 **약 1 mL**(용해도가 낮으면 **DCM**)를 넣고 충분히 돌려 씻어 컬럼에 옮긴다. 실리카에 흡수시킨다.
5. **Rinsing 2**: 용리액 **약 2-3 mL**로 다시 헹궈 옮기고 흡수시킨다.

**flash 컬럼 실행**
6. 준비한 용리액 **약 200 mL**를 컬럼에 **조심스럽게**(실리카를 교란하지 않게) 가한다. **공기 압력**을 가해 용리액을 **시험관**에 받는다.
7. 각 시험관의 조성을 **TLC**로 분석한다(플레이트 하나에 **4-6개 점**, 모세관은 **acetone으로 씻어 재사용** 가능).
8. 출발 물질과 생성물 모두 **UV 활성이 없으므로 KMnO₄ 염색**으로 점을 본다.
9. 생성물이 나오지 않으면 용리액을 더 가하거나 **극성을 높인다.** 목적 생성물이 모두 나올 때까지 컬럼을 계속한다.
10. 생성물이 든 모든 fraction을 **건조하고 질량을 잰 100 mL 또는 250 mL 둥근바닥플라스크**에 모아 **회전증발기**로 용매를 제거한다(여러 번에 나눠 할 수 있음).
11. 용매를 완전히 없애기 위해 **진공에서 20분** 더 건조한다. 정제된 생성물의 질량을 기록한다.

### 2.4 특성 분석 [M p26]
계산(수득량), **IR**, **¹H NMR**. datasheet: 출발물질(6-methyl-5-hepten-2-one, vinylmagnesium bromide)의 양(mL), 조생성물(빈 플라스크, 생성물+플라스크, 질량), 정제 생성물 질량, 관찰, **TLC 플레이트 그림에 모든 거리(cm)**, 사진 측정 기록 + TA 서명(인쇄본). [M p27]

## 4. "왜?"를 묻는 문제에 대비한 이유 정리

| 질문 | 답 | 근거 |
|---|---|---|
| 왜 유리기구를 진공에서 가열해 건조하는가? | 유리 표면에 흡착된 **얇은 수분 막**을 제거하기 위함. Grignard는 물과 즉시 반응 | [초안; M p20] |
| 왜 진공-질소 사이클을 반복하는가? | 반복할 때마다 잔류 공기를 더 줄임 | [초안] |
| 왜 주사기를 N₂로 purge하고 바늘을 빼기 전에 N₂를 조금 빨아들이는가? | Grignard가 공기와 닿지 않게 하고 용액이 바늘에서 떨어지는 것을 막음 | [M p22] |
| 왜 병을 클램프로 고정하고 질소 아래에 두는가? | 제조사가 질소 하에 포장했으므로 공기에 노출시키면 안 됨 | [M p22] |
| 왜 얼음-물 배스에서 가하는가? | 발열 반응이므로 온도를 낮춰 조절 [추론]. 매뉴얼은 5-10분 식힌 뒤 dropwise 첨가라고만 기술 | [M p22] |
| 왜 포화 NH₄Cl로 quench하는가? | **약산**으로 마그네슘 알콕시드를 양성자화하고 남은 Grignard를 파괴. 3차 알릴 알코올인 linalool은 **강산에서 탈수나 재배열**이 쉬우므로 강산을 피함 | [M p23-24; 초안] |
| 왜 quench 시 얼음 배스에서 한 방울씩인가? | 남은 Grignard와의 반응이 발열이고 기체(ethylene)가 나오기 때문 [추론] | [M p23-24] |
| 왜 brine으로 씻는가? | 유기층에 녹은 물을 대부분 제거 [G, Exp 3 초안과 같은 논리] | [M p24] |
| 왜 KMnO₄ 염색인가? | 출발 물질과 생성물 모두 **UV 비활성**. KMnO₄는 두 화합물에 있는 **C=C**와 반응해 점이 보임 | [M p24, p26; 초안] |
| 왜 생성물이 컬럼에서 늦게 나오는가? | 알코올은 **수소결합 주개**라 케톤보다 **극성이 크므로** 실리카에서 더 오래 머물고 **Rf가 낮음** | [초안] |
| 생성물이 나오지 않으면? | 용리액을 더 가하거나 **극성을 높인다** | [M p26] |
| 왜 실리카를 흄후드에서 다루는가? | 실리카 분말은 흡입하면 **독성** | [M p24] |

## 5. 분석 해석 [초안, 예상값]

### IR
- 출발 케톤의 강한 **C=O 신축(약 1715 cm⁻¹)**이 **사라지고**, 알코올의 넓은 **O-H 신축**이 나타난다(약 3500-3200 cm⁻¹). [초안]
- 비닐기의 =C-H 면외 굽힘(약 990, 910 cm⁻¹)이 새로 나타남(케톤에는 없음). [초안 표]

- 핵심 변화: **메틸 케톤 단일선(약 2.1 ppm)이 사라지고** 카비놀 탄소의 메틸 단일선(약 1.3 ppm)이 나타남. 세 개의 한 개짜리 신호(약 5.9, 5.2, 5.0)가 **일치환 알켄의 전형적 패턴**. 내부 비닐 H는 두 말단 H와 결합하며 **trans 결합 약 17 Hz, cis 결합 약 11 Hz**로 dd. [초안]
- 삼치환 알켄(-CH=C(CH₃)₂)은 출발물질과 생성물 모두에 있어 변화를 구별하는 데 쓸 수 없음. [초안]
- 2.1 ppm에 남은 단일선은 미반응 케톤. 수분에 의한 Grignard 손실이나 enolization 때문일 수 있음. [초안 주석]

## 6. 자주 틀리는 곳 (틀린 서술 → 올바른 서술)

| 틀린 서술 | 올바른 서술 | 근거 |
|---|---|---|
| 플라스크는 오븐에서 말려 바로 쓴다 | **Schlenk line에서 진공 + 열풍기**로 가열 건조, N₂ 채움을 **2회** | [M p21] |
| 열풍기로 가열할 때 흄후드에 용매가 있어도 된다 | **인화성 화학물질이나 용매가 없어야** 한다 (열풍기 300-500 °C) | [M p20] |
| 가열 직후 곧바로 시약을 넣는다 | **실온까지 식힌 뒤** 시약을 넣는다 | [M p21] |
| 반응은 공기 중에서 한다 | **질소 분위기**, 무수 THF | [M p19-22] |
| Grignard는 한꺼번에 가한다 | **한 방울씩(dropwise)**, 냉각한 플라스크에 | [M p22] |
| 반응은 얼음 배스에서 90분 | 첨가 후 **얼음 배스를 제거**하고 **실온에서 90분** | [M p23] |
| vinylmagnesium bromide는 1 mmol만 쓴다 | **7.5 mL (7.5 mmol, 2.5 eq)** | [M p20] |
| 주사기의 남은 Grignard는 그대로 버린다 | **포화 NH₄Cl로 quench**(waste fumehood), 이어 **sharp container**에 | [M p23] |
| quench는 6 M HCl로 | **포화 NH₄Cl** 10 mL (약산) | [M p23] |
| 추출은 ethyl acetate로 1번 | **총 3번**(플라스크 헹굼 20 mL + 20 mL × 2), 합친 유기층 약 60 mL | [M p23-24] |

| Na₂SO₄ 건조는 즉시 여과 | **15분** 둔다 | [M p24] |
| TLC는 UV로 확인 | 출발물질과 생성물 모두 UV 비활성이므로 **KMnO₄ 염색** | [M p24, p26] |

## 7. 안전과 폐기물 요약
`../safety.md`의 "유기 실험 4" 절. 핵심: vinylmagnesium bromide는 독성이고 물과 닿으면 인화성 기체(ethylene)를 방출, 열풍기 300-500 °C, 바늘 주의, hexane은 신경독성(neurotoxin), 실리카 분말은 흡입 독성, 주사기는 sharp container, 잔류 Grignard는 NH₄Cl로 quench. [M-유기 p20-24]
